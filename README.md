# AI Agent Delivery Casebook

这是一个 AI Agent 交付案例库。

通过业务场景拆解，探索：

- Agent
- Workflow
- Human

三者之间的边界设计，以及 AI 应用落地过程中的交付方法。

> 案例为模拟业务场景，用于展示业务分析、方案设计和交付思考过程。

---

## Method

每个案例关注四个核心问题：

1. 业务问题是什么？
2. 哪些环节适合 Workflow 自动执行？
3. 哪些环节需要 Agent 进行综合判断？
4. 哪些情况必须保留 Human 介入？

目标不是追求最大化自动化，而是设计可靠、可验证、可持续的人机协作流程。
